# Aura – Web

Die Web-Fassung von Aura für iPad, iPhone und Browser, ausgeliefert über
GitHub Pages unter https://aura.tr-management.de.

Die Dateien hier werden erzeugt, nicht von Hand gepflegt: Quelle ist
`web/` und `src/` im Repo `tobiasrisel/Aura-digital-Assistant`
(`web/bauen.sh` → Inhalt von `web/dist`).

Enthält nur die Oberfläche und den öffentlichen Supabase-Projektschlüssel.
Zugang zu Daten, Modell und Stimme gibt es erst nach Anmeldung einer
freigegebenen Adresse; die Schlüssel liegen in den Supabase-Function-Secrets.
